# Disaster Management Platform

This repository contains the React frontend and Node.js backend for the Disaster Management Platform, developed by TeamSecure-GITA.

## Backend

Backend for our Disaster Management Platform developed by TeamSecure-GITA.

## About

This backend handles user authentication, disaster alerts,
SOS requests, shelters, resources, volunteers, sensors,
drones, notifications and other services required by the
platform.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Socket.IO

## Features

- User authentication
