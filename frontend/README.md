# 🌐 Autonomous Disaster Management Platform - Frontend Command Center

A high-performance, real-time situational awareness and autonomous disaster response command console engineered with Next.js App Router, Tailwind CSS, Leaflet/MapLibre, WebSockets, and P2P Mesh capabilities.

## 🚀 Key Modules & Architecture

- **Dashboard**: Real-time situation feed, regional risk indices, AI executive briefings, system telemetry health.
- **AI Copilot**: Interactive multi-turn conversational command copilot, tool executions, real-time situation briefs, multi-lingual voice dispatch.
- **Intelligence**: Spatial hazard heatmaps, geotechnical landslide predictions, atmospheric forecasting, sensor anomaly detection, SHAP/LIME explainability.
- **Analytics**: Real-time and historical multi-incident analytics, shelter capacities, responder resource saturation, ML performance tracking.
- **Response**: Autonomous evacuation route planning, emergency dispatch orchestration, responder telemetry, shelter status.
- **Sensors**: IoT telemetry stream, LoRaWAN mesh relay, geotechnical tiltmeter/seismograph health, automated threshold anomaly monitoring.
- **Drone Swarm**: Autonomous search & rescue missions, live thermal/IR video feed, edge AI survivor identification.
- **Simulation**: Digital Twin 3D sandbox, multi-hazard cascade models, geotechnical what-if parameters.
- **Innovation / Deep-Tech**: Post-Quantum Cryptography (PQC), RF-CSI Wi-Fi human presence sensing, WebAssembly offline prediction engine, ultrasonic audio mesh, AR survivor SOS.

## 🛠️ Development & Deployment

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
