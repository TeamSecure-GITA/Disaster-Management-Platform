# Disaster Management Autonomous Command Platform Overview

## High-Level System Architecture
1. **Decentralized Edge-AI Mesh**: LoRaWAN (865 MHz IN) + P2P WebRTC / Audio FSK modem fallback.
2. **AI Copilot Core**: Gemini 1.5 Pro multimodal reasoning agent with strict safety guards and tool orchestration.
3. **ML Prediction Engine**: Geotechnical Mohr-Coulomb landslide failure models, hydrodynamic flood routing, and SAR satellite interferometry.
4. **Responder Dispatch & Tracking**: Real-time GPS/VHF unit coordination, digital triage stamps, and shelter capacity tracking.
